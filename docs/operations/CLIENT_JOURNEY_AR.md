# رحلة العميل داخل نظام PG Integrated

هذا الملف يشرح رحلة العميل من لحظة إنشاء حسابه وحتى استلام آخر ملف أو رابط تسليم من لوحته الخاصة.

## 1. إنشاء العميل من لوحة التحكم

المسار:

`Dashboard → Clients → New Client`

الخطوات:

1. إضافة اسم العميل واسم الشركة.
2. إضافة البريد الرسمي للعميل.
3. تفعيل خيار `Enable client portal`.
4. تعيين كلمة مرور للعميل.
5. حفظ العميل.

بعد ذلك يستطيع العميل الدخول من:

`/client/login`

## 2. دخول العميل

يدخل العميل باستخدام:

- البريد المسجل في ملف العميل.
- كلمة المرور التي تم إنشاؤها له من لوحة التحكم.

بعد الدخول ينتقل إلى:

`/client`

## 3. لوحة العميل الرئيسية

تحتوي لوحة العميل على:

- عدد المشاريع.
- عدد الوظائف أو الطلبات النشطة.
- عدد الملفات أو المشاريع المسلّمة.
- حالة ملف العميل.
- الطلبات المفتوحة.
- تقويم مناسبات وتسويق حسب دولة العميل.
- آخر حالة للـ jobs والمراحل والتواريخ.

## 4. صفحة بيانات العميل والشركة

المسار:

`/client/profile`

يستطيع العميل تحديث:

- اسم جهة التواصل.
- اسم الشركة.
- الصناعة.
- الدولة والمدينة.
- رقم الهاتف.
- الموقع الإلكتروني.
- صورة البروفايل.
- نبذة عن الشركة.

هذه المعلومات تساعد فريق PG Integrated على فهم العميل عند استقبال Brief أو Campaign جديد.

## 5. صفحة المشاريع

المسار:

`/client/projects`

تحتوي على:

- المشاريع الحالية.
- المشاريع السابقة.
- عدد jobs داخل كل مشروع.
- حالة المشروع.
- روابط الملفات مثل Dropbox أو Brief link.
- روابط التسليم النهائي مثل WeTransfer أو Final delivery link.
- الطلبات التي أرسلها العميل.

## 6. طلب مشروع أو بريف أو حملة جديدة

المسار:

`/client/requests/new`

يمكن للعميل إرسال:

- Brief.
- Campaign.
- Project.
- Job.
- Adaptation.

الحقول المتاحة:

- نوع الطلب.
- المشروع المرتبط، أو طلب جديد غير مرتبط بمشروع سابق.
- عنوان الطلب.
- وصف البريف.
- الدولة المستهدفة.
- تاريخ الإطلاق المطلوب.
- الميزانية المتوقعة.
- الأولوية.
- Deliverables.
- روابط خارجية مثل WeTransfer أو Dropbox أو Drive.
- مرفقات متعددة.

بعد الإرسال يظهر الطلب في لوحة الأدمن:

`/admin/client-requests`

## 7. مراجعة الطلب من الأدمن

فريق PG Integrated يدخل إلى:

`Dashboard → Clients → Client Requests`

ثم يراجع:

- بيانات العميل.
- نوع الطلب.
- البريف.
- المرفقات.
- الروابط.
- الدولة والتاريخ.
- الأولوية.

بعد ذلك يمكن تحويل الطلب إلى مشروع أو Job ضمن عملية الترافيك.

## 8. متابعة التنفيذ

بعد إنشاء Job أو Project، يرى العميل:

- اسم المهمة.
- المشروع المرتبط.
- المرحلة الحالية.
- نسبة الإنجاز.
- موعد التسليم.
- روابط الملفات.

## 9. استلام الملفات النهائية

عند اكتمال المشروع أو Job:

1. يتم إضافة رابط التسليم النهائي في `Final delivery path`.
2. يمكن أن يكون الرابط WeTransfer أو Dropbox أو Drive.
3. يظهر الرابط للعميل داخل `/client/projects`.
4. العميل يفتح الرابط ويحمل الملفات.

## 10. نهاية رحلة العميل

تنتهي الرحلة عندما:

- يرى العميل المشروع أو Job مكتمل.
- يظهر رابط التسليم النهائي.
- تكون الملفات قابلة للتحميل.
- يتم أرشفة المشروع أو إبقاؤه كمرجع سابق.
